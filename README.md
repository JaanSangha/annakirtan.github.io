# Anna Lisa Kirtan

Static website for [annakirtan.github.io](https://annakirtan.github.io), hosted on GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a simple static server:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Pages

- `index.html` — Home
- `cd.html` — CD
- `events.html` — Events
- `video.html` — Videos
- `about.html`, `contact.html`, `pictures.html` — Additional pages (not in main nav)
